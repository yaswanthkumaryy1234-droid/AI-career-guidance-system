# AI Career Guidance System

An AI-powered web application developed using Django and Machine Learning that helps users identify suitable career paths based on their skills, interests, and academic performance.

---

## 🚀 Features

- User Authentication System
- AI-Based Career Prediction
- Career Recommendation Dashboard
- User Profile Management
- Career History Tracking
- Machine Learning Integration
- Responsive User Interface

## ⚙️ Installation Guide

### 1. Clone the Repository

```bash
git clone https://github.com/yaswanthkumaryy1234-droid/AI-career-guidance-system.git
```

### 2. Navigate to Project Folder

```bash
cd AI-career-guidance-system
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux/Mac

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Migrations

```bash
python manage.py migrate
```

### 7. Start Development Server

```bash
python manage.py runserver
```

### 8. Open in Browser

```bash
http://127.0.0.1:8000/
```
